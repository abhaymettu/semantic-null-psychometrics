# Data

No survey response data, and no statistic computed from survey responses, is in this repository. Two fingerprints are kept so a rebuild can be checked: a SHA-256 of the host file (`sources.json`) and a git object id (SHA-1) of the rebuilt DASS-42 correlation matrix (`integration/r3_heldout.py`). Neither discloses a value.

- `items/`: item text and keys (public domain; see `NOTICE.md`).
- `fixtures/`: synthetic data generated by `scripts/build_aggregates.py` (`make_fixtures`), used by the tests.
- `sources.json`: download URL and sha256 for each source file.

To rebuild the item-level aggregates the analysis code reads, download the sources yourself and build them locally:

```sh
python -I scripts/fetch_data.py      # downloads into data/cache/ (git-ignored) and checks each sha256
uv run --python 3.13 --with numpy==2.3.3 --with scipy==1.16.2 python -I scripts/build_aggregates.py dass42 fixtures
SEMNULL_CACHE=data/cache python -m integration.neff   # writes integration/out/dass42_neff.json, read by level_sweep, split, r3_heldout
```

## How the aggregates are built

- **Direction.** A higher category means more agreement with the item text as worded, the direction an embedding of the
  text sees. DASS-42 responses 1 to 4 are recoded to the published 0 to 3 scale; every DASS item is keyed the same way.
- **Pearson** is computed on the category scores. **Polychoric** is a two-step estimate: thresholds come from each pair's
  own marginals, then rho is found by maximum likelihood (golden-section search over (-0.9999, 0.9999); the bivariate
  normal CDF uses Owen's T). No smoothing is applied.

The DASS-42 response file (openpsychometrics.org/_rawdata/) is posted for public download without a stated licence, so
it is not redistributed here, and neither is any statistic computed from it. Use of it is your own decision.
These outputs are git-ignored here (`data/aggregates/`, `integration/out/`, `figs/`) so a local rebuild is never committed.
